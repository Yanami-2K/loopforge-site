# 新手常见问题与排障速查

> **常见问题 · FAQ** · 遇到黄字提醒、按钮点不动、或者找不到项目和任务时，按下面的分类找到对应现象，照着步骤点即可解决。右侧「本页目录」可以直接跳转到具体问题。

## 一、凭证与模型配置问题

### 1. 输入框上方提示「当前执行器 CodeBuddy 需要先配置 CodeBuddy API Key」或「请先在个人配置中配置 XXX API Key」

* **为什么会这样**：你当前选中的 Coding Agent CLI 还没有配置对应的个人 API Key，因此它还不能开口回答或写代码（但**不影响**你点击首页的「一键体验」跑免 Key 脚本流程）。
* **怎么解决**：
  1. 直接点击提示条右侧的 **「去配置」** 按钮（系统会自动跳转到「设置 → 个人配置」并定位到对应凭证卡片）。
  2. 在 **「模型与执行」** 区域填入该 CLI 的 API Key 并保存。
  3. 如果你已经配过了 `Codex` 或 `Claude Code` 等其他 CLI 的 Key，也可以直接在聊天输入框下方点开 **`CLI`** 菜单切换过去使用。

### 2. 配置 CodeBuddy API Key 时提示「这像是 DeepSeek、OpenAI 等第三方模型的 Key，CodeBuddy 会拒绝」

* **为什么会这样**：你把以 `sk-` 开头的第三方大模型密钥贴进了 CodeBuddy 凭证框。CodeBuddy 的官方密钥以 `ck_` 开头，且必须与下方所选的发卡站点（`国际站 codebuddy.ai` 或 `国内站 copilot.tencent.com`）一致，填入第三方 Key 会在调用时报 `401` 错误。
* **怎么解决**：
  * 如果你打算用 CodeBuddy，请点击配置向导里的站点链接前往 CodeBuddy 对应站点创建 `ck_` 密钥。
  * 如果你手里拿的是 DeepSeek、Moonshot、OpenAI 或兼容网关的 `sk-` 密钥，请关闭当前卡片，改填到 **「个人配置 → 模型与执行」** 下的 **`DeepSeek Harness`、`Kimi Code`、`OpenCode`、`Claude Code` 或 `Codex`** 凭证中，并按需填写 Base URL。

### 3. 配置 OpenCode、Pi 或 Antigravity 时无法保存，提示「请填写 Base URL」

* **为什么会这样**：
  * `OpenCode` 和 `Pi` 本身不提供官方托管的模型服务，必须接入你指定的模型服务地址才能工作。
  * `Antigravity` 在选择 `Gemini 官方 API` 时免填地址，但一旦切换为 `OpenAI 兼容网关（Chat Completions）` 模式，就必须提供网关地址。
* **怎么解决**：在凭证编辑框的 **Base URL** 栏填入以 `http://` 或 `https://` 开头的完整服务地址，并确认下方的 **接口协议**（`Chat Completions` / `Responses` / `Messages`）与你的网关一致后再点击保存。

## 二、对话与输入框操作问题

### 4. 聊天输入框右下角的「发送箭头」是灰色的，点不动

* **为什么会这样**：通常由以下三种情况之一引起：
  1. 输入框左上角的项目按钮还停留在 **「选择项目」**，尚未选定本次对话归属的项目；
  2. 输入框里还没有输入任何文字；
  3. 上一轮回复正在生成中（此时右下角会变为停止按钮，或者发送新消息会进入排队托盘）。
* **怎么解决**：先看一眼输入框左上角，如果写着 **「选择项目」**，点开选中 **`LoopForge 体验项目`**（或你的业务项目），输入文字后发送按钮就会亮起。

### 5. 为什么「需求列表」右上角已经是体验项目，但聊天框里却显示「选择项目」？

* **为什么会这样**：为了防止你在没注意的情况下把新对话发进错误的项目工作区，当你第一次打开浏览器、还没主动在聊天框里挑过项目时，聊天框会要求你明确选定一次（只有「一键体验」卡片会自动进入体验项目）。
* **怎么解决**：在聊天框左上角点一下 **「选择项目」** 并选中目标项目即可。选过一次后，浏览器会自动记住你的偏好，后续新建对话无需再重复选。

### 6. 在已有回复的对话里切换另一个 CLI（如从 CodeBuddy 换到 Claude Code），为什么会自动开启新对话？

* **为什么会这样**：每一种 Coding Agent CLI 的底层会话都保存着各自专属的工具调用轨迹和推理状态，不同 CLI 之间无法中途接力恢复同一个原生会话。
* **怎么解决**：这是正常的保护机制。当你在已有回复的会话底部切换 `CLI` 时，系统会自动为你打开一条使用新 CLI 的空白对话；如果你还想看刚才那条对话的内容，随时可以在左侧「个人对话 / 团队会话」列表里点回去。

## 三、流程运行与项目账号问题

### 7. 刚点完首页的「一键体验」，去「需求列表」看为什么还是空的？

* **为什么会这样**：首页的「一键体验」直接启动了一条独立的验收运行（Standalone Run：`平台验收 · 脚本与审批`），用来带你体验脚本节点和人工审批，并不会在需求列表里凭空塞入一条虚假的需求单。
* **怎么解决**：点击左侧图标栏第 6 个播放键图标 **「运行记录」**（或第 4 个盾牌图标 **「待我确认」**），就能看到刚才那次运行以及它生成的 `reports/welcome.md` 验收报告了。

### 8. 任务好像停住了，既没有红色报错，也没有继续往下走

* **为什么会这样**：流程大概率跑到了 **人工审批关口（Human Gate）**，或者在对话流里弹出了 **待确认操作卡片**（`每次确认` 模式下修改平台数据前会先询问你），正在等你拍板。
* **怎么解决**：
  * 看一眼左侧图标栏第 4 个图标 **「待我确认」** 上有没有亮起红色数字角标，点进去即可选择「确认通过」或「退回返工」。
  * 如果是在对话里觉得卡住了，直接回 AI 工作台问一句：`这条任务现在卡在哪一步，需要我点什么？`

### 9. 登录页只有「登录」按钮，没有看到「还没有账号？注册」

* **为什么会这样**：你们团队的管理员在服务器配置（`.env` 中的 `AGENTFLOW_ALLOW_SIGNUP=false`）中关闭了公开自助注册。
* **怎么解决**：请联系你们团队的平台管理员，由管理员进入 **「设置 → 平台管理 → 成员账号」** 为你创建用户名和初始密码；忘记密码时同样由管理员在该页面一键重置。

## 四、向同事或社区求助时的「安全截图原则」

如果对照上面的问答还是没能解决你的问题，最省事的办法就是**把当前浏览器页面截一张图**发给帮你部署平台的同事，或者发到 LoopForge 交流群。

在发截图或复制文字求助前，请务必遵守一条安全铁律：

* **可以放心展示的信息**：页面 URL、需求编号（如 `LOOP-12`）、运行编号（`Run ID`）、节点拓扑图状态、红色的报错提示文字。
* **严禁发进群聊或公开贴出的信息**：你在「个人配置」里填写的各家 **API Key**、**GitHub Personal Access Token**、**个人 API Token 明文** 以及 `.local/admin-password` 中的管理员密码。
